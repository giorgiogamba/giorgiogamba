# Hi, I'm Giorgio Gamba

I am a Software Engineer based in Turin, specialize in building robust, low-level systems. My work sits at the intersection of high-performance C++ development and creative technology. * **Systems Programming:** Advanced C++ (17/20), and real-time communication (DDS).
